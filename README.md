## Features

- Dashboard
- Student List

- Delete Student

- Filter Students
- Student Sorting
- Form Validation
- Responsive Design

## How to Run

1. Download or clone the project.
2. Open the project in Visual Studio Code.
3. Install the Live Server extension.
4. Right-click `index.html`.
5. Select **Open with Live Server**.
